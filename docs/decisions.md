| D-014 | 2026-09-24 | The nonce-based CSP is delivered as a `<meta http-equiv>` tag in the page head; `.htaccess` sends only `frame-ancestors` + `upgrade-insecure-requests` as a header | Hostinger's LiteSpeed replaces the `Content-Security-Policy` **header** PHP sends with its own `upgrade-insecure-requests`, silently losing the whole policy. A `.htaccess` header is applied last so it wins the value back, but it is a fixed string and cannot carry a per-request nonce. A meta tag can, and no host can rewrite it. `frame-ancestors` is the one directive browsers ignore in meta, so it stays in the header; browsers enforce the intersection of both. `App\Middleware\SecurityHeaders::cspDirectives()` is the single source of truth | Accepting the host's weak CSP; a static `.htaccess` policy with `'unsafe-inline'` (drops the nonce); asking Hostinger support to disable their header (out of our control) |
