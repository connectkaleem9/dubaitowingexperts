53. KEYWORD MAPPING PHILOSOPHY
============================================================

Do NOT add every keyword to every page.

Use:

Keyword
    ->
Search Intent
    ->
Keyword Cluster
    ->
Page Type
    ->
URL
    ->
Primary Keyword
    ->
Secondary Keywords
    ->
Content
    ->
Internal Links
    ->
Conversion

Examples:

"car recovery Dubai"
    ->
Commercial
    ->
Car Recovery Service
    ->
/services/car-recovery/

"car recovery Dubai Marina"
    ->
Local Commercial
    ->
Dubai Marina Area
    ->
/areas/dubai-marina/

"what to do when car breaks down in Dubai"
    ->
Informational
    ->
Guide
    ->
/blog/car-breakdown-dubai/

This approach provides broad keyword coverage without keyword stuffing or unnecessary duplicate pages.
