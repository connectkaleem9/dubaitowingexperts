# Conversion Optimization

Read CLAUDE.md before using this skill.

## Purpose
Turn visits into calls, WhatsApp chats and form leads.

## Inputs
- Page template
- Analytics data if available

## Process
1. Primary CTA above fold; sticky mobile bar.
2. Context-aware WhatsApp prefill per service/area.
3. Minimise form fields; clear errors.
4. Reinforce with real reviews/projects near CTAs.

## Rules
- No dark patterns, fake urgency or fake scarcity.
- Every CTA has data-track.

## Output
Updated templates/partials

## Validation checklist
- [ ] Call/WhatsApp visible at every scroll position on mobile
- [ ] All CTAs fire events
- [ ] Form works without JS
